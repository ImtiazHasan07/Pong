# Pong Game

Welcome to the Pong Game project, a JavaScript application built using HTML5 Canvas. This project recreates the classic Pong arcade game with a simple and interactive browser-based interface.

## Features

* Classic Pong gameplay
* Player vs player (local) controls
* Smooth ball movement and collision detection
* Score tracking system

## Prerequisites

Before running the Pong Game, ensure you have the following:

* A modern web browser (Chrome, Edge, Firefox, etc.)

## Installation

Follow these steps to get your Pong Game up and running:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/imtiazhasan07/pong.git
   cd pong
   ```

## Usage

To launch the Pong Game, simply open the HTML file in your browser:

```bash
open index.html
```

Or manually open `index.html` in your preferred web browser.

Once loaded, use your keyboard to control the paddles and start playing.
